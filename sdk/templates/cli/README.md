# Limoxel SDK Custom CLI Template

A CLI tool scaffolding demonstrating how to build custom command-line utilities using the Limoxel SDK with flag parsing and subcommands.

## Usage

```bash
# Run inspect action
go run main.go -action=inspect -repo=.

# Run health analysis action
go run main.go -action=health -repo=.

# Export graph
go run main.go -action=graph -repo=.
```
