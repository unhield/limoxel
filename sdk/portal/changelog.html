Release History

Release History & Changelog

Official release record of the Limoxel Engineering Knowledge Infrastructure platform and SDK.

Version 1.5.1 Current Release

2026-09-21

Security & Storage Boundary Hardening

  • Hardened marketplace storage path resolution with defensive containment checks at the filesystem boundary.
  • Enforced content-addressed SHA-256 digest validation across plugin artifact and metadata storage operations.
  • Strengthened process-file locking to prevent lock files from escaping configured storage roots.

Reliability & Process Isolation

  • Enhanced OS process group isolation and lifecycle management for out-of-process execution.
  • Guaranteed clean subprocess tree termination on Unix (process groups via setpgid) and Windows (Job Objects).
  • Improved resource limiter enforcement and error classification under bounded test execution.

Continuous Integration

  • Restored GitHub Actions workflow to exactly 4 dynamically discovered, round-robin balanced test shards.
  • Enforced race detection, atomic coverage profiling, and aggregated coverage consolidation across all 4 shards.

Version 1.5.0

2026-09-20

Plugin Framework & Ecosystem

  • Added extensible Limoxel Plugin Framework supporting defined extension contracts and capability declarations.
  • Added deterministic plugin lifecycle state machine (installed, active, suspended, terminated).
  • Added public Plugin SDK for developing third-party analysis, repository, and graph extensions.

Security & Isolation

  • Added cryptographic plugin signature verification and publisher trust validation.
  • Introduced multi-tier permission controls across filesystem, network, configuration, and runtime resources.
  • Added process-level sandboxing with memory, CPU, and process count quotas.

Marketplace Infrastructure

  • Added marketplace catalog management, version indexing, and semantic dependency resolution.
  • Introduced publisher verification, community review models, and rating infrastructure.

Version 1.4.0

2026-08-28

Public Go SDK Layer

  • Introduced the public Go SDK under github.com/unhield/limoxel/sdk.
  • Exposed 11 stable capability contracts: Repository, File, Package, Symbol, Search, Graph, Analysis, Navigation, Reasoning, Events, and Intelligence.
  • Added Knowledge Graph export supporting Mermaid flowchart and Graphviz DOT formats.
  • Added multidimensional codebase health evaluation and circular dependency detection.
  • Added blast-radius change impact analysis and refactoring safety guidance.
  • Introduced zero-dependency Developer Portal with interactive API Explorer and Example Gallery.

Semantic Versioning & Compatibility Policy

The Limoxel platform strictly adheres to Semantic Versioning 2.0.0. Major releases indicate breaking changes, Minor releases add backward-compatible capabilities, and Patch releases provide backward-compatible bug and security fixes.
