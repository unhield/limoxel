Developer Guide & Best Practices

1. Architecture & Design Principles

The Limoxel SDK exposes high-level, thread-safe public contracts that wrap underlying repository indexers, graph databases, and intelligence reasoning engines. Consumers interact solely with the *sdk.Client coordinator and its capability accessors.

2. Lifecycle & Resource Management

Always invoke defer client.Close() immediately after initializing a client. This releases file descriptor indexers, background worker pools, and memory caches cleanly.

client, err := sdk.New(sdk.WithWorkspace("/path/to/repo")) if err != nil { return err } defer client.Close() // Release background workers and file handles

3. Context Cancellation & Timeouts

Every SDK method accepts a standard context.Context. For long-running operations like deep graph traversal or whole-repository health analysis, pass a context with a suitable timeout (e.g. 30s to 60s).

4. Error Handling & Semantic Categories

Limoxel errors conform to the sdk.SDKError interface. Inspect sdkErr.Category() to programmatically handle missing entities (CategoryNotFound), invalid arguments (CategoryInvalidInput), or lifecycle state issues (CategoryInvalidState).

5. Concurrency & Goroutine Safety

A single *sdk.Client instance is completely safe for concurrent access across multiple goroutines. You can share one client across HTTP request handlers or background workers without external mutex locking.
