The Engineering Knowledge Infrastructure (EKI) Model

As software systems expand across services, packages, and teams, system structure becomes opaque. Limoxel provides an authoritative, queryable model of software reality. The Go SDK exposes these core infrastructure capabilities through 11 contract-driven, thread-safe interfaces.

01

Deterministic Code Modeling

Parse, index, and resolve symbols, types, packages, and files with syntax-level precision and verifiable provenance.

02

Structural Knowledge Graph

Traverse typed dependency edges, inspect call chains, and export graph topologies directly to Mermaid and Graphviz DOT formats.

03

Architectural Governance

Quantify multidimensional codebase health, enforce architectural layer rules, and detect circular dependencies in CI gates.

04

Semantic Code Navigation

Resolve symbol definitions, find reference sites across repository boundaries, and compute incoming and outgoing call hierarchies.

05

Change-Impact Reasoning

Compute downstream blast radii for proposed structural changes, evaluate breaking change risks, and receive refactoring safety guidance.

06

Asynchronous Event Streams

Subscribe to typed repository lifecycle, indexing milestones, and analysis completion events over thread-safe Go channels.

Verified Quickstart

Initialize a workspace client and assess repository health in fewer than 15 lines of code:

package main import ( "context" "fmt" "log" "time" "github.com/unhield/limoxel/sdk" ) func main() { ctx, cancel := context.WithTimeout(context.Background(), 30*time.Second) defer cancel() client, err := sdk.OpenWorkspace(ctx, ".") if err != nil { log.Fatalf("failed to open workspace: %v", err) } defer client.Close() health, err := client.Analysis().RepositoryHealth(ctx) if err != nil { log.Fatalf("health analysis failed: %v", err) } fmt.Printf("Health Score: %.1f/100 (Grade: %s)\n", health.OverallScore, health.Grade) fmt.Printf("Total Files: %d, Total Symbols: %d\n", health.Metrics.TotalFiles, health.Metrics.TotalSymbols) }
