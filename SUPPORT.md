# Support

Thank you for your interest in Limoxel.

This document explains how to obtain assistance, ask questions, report non-security issues, and communicate with the project maintainers.

---

# Before Requesting Support

Before requesting assistance, please ensure that you have:

- Read the project documentation.
- Reviewed the README.
- Checked existing GitHub Issues and Discussions.
- Verified that you are using a supported version of Limoxel.
- Attempted to reproduce the issue using the latest version.

Many common questions are answered within the project's documentation.

---

# Documentation

The official documentation is the primary source of information for Limoxel.

Before opening a support request, please consult the relevant engineering documentation located in the `docs/` directory.

Documentation includes:

- Foundation
- Architecture
- Engineering
- Repository Structure
- Development Guidelines

---

# Getting Help

If you require assistance using Limoxel, you may use one of the following channels.

## GitHub Discussions

GitHub Discussions are the preferred location for:

- General questions
- Usage guidance
- Best practices
- Design discussions
- Community knowledge sharing

---

## GitHub Issues

GitHub Issues should be used for:

- Reproducible bugs
- Unexpected behavior
- Documentation problems
- Enhancement suggestions

Please provide sufficient information to help reproduce the issue.

---

## Email

If you need to contact the project maintainer directly, you may email:

**hello.limoxel@gmail.com**

Email is appropriate for matters that are not suitable for public discussion.

---

# Security Issues

Do **not** report security vulnerabilities through GitHub Issues or Discussions.

Please refer to **SECURITY.md** for the responsible disclosure process.

---

# Response Expectations

Support is provided on a best-effort basis.

Response times may vary depending on:

- Issue complexity
- Project priorities
- Maintainer availability

While every reasonable effort will be made to respond, immediate assistance cannot be guaranteed.

---

# Scope of Support

Support may include:

- Installation guidance
- Build issues
- Configuration questions
- Usage assistance
- Documentation clarification
- Bug investigation
- Development guidance

Support does not include:

- Custom feature development
- Project-specific consulting
- Priority support
- Custom integrations
- General software development services

---

# Engineering Discussions

Questions regarding engineering decisions, architecture, repository organization, or long-term platform direction are welcome.

Technical discussions are encouraged provided they remain respectful, constructive, and evidence-based.

---

# Project Status

Limoxel is an actively evolving engineering platform.

Feature requests and improvement ideas are welcome, although implementation priorities are determined according to the project's long-term engineering roadmap.

---

# Thank You

Thank you for supporting Limoxel.

Community feedback, thoughtful questions, reproducible bug reports, and constructive discussions all contribute to improving the engineering quality of the project.
