# Code of Conduct

## Our Commitment

Limoxel is committed to maintaining a respectful, professional, and collaborative community.

We welcome contributors from diverse backgrounds, experiences, and perspectives who share an interest in advancing high-quality engineering.

Every participant is expected to contribute in a manner that promotes constructive collaboration, mutual respect, and technical excellence.

---

# Expected Behavior

Members of the Limoxel community are expected to:

- Treat others with professionalism and respect.
- Engage in constructive technical discussions.
- Welcome thoughtful questions and different viewpoints.
- Accept feedback professionally.
- Base technical discussions on evidence and engineering reasoning.
- Help maintain a welcoming environment for contributors of all experience levels.
- Respect project decisions made through the established review process.

---

# Unacceptable Behavior

The following behaviors are not acceptable within the Limoxel community:

- Harassment, discrimination, or intimidation.
- Personal attacks or abusive language.
- Deliberate disruption of discussions or project activities.
- Publishing private or confidential information without permission.
- Spam, trolling, or intentionally inflammatory behavior.
- Knowingly submitting malicious code or security vulnerabilities without responsible disclosure.
- Repeatedly ignoring established project guidelines after review and feedback.

---

# Engineering Discussions

Technical disagreements are a normal part of software engineering.

Contributors are encouraged to challenge ideas, designs, and implementations through respectful, evidence-based discussion.

Engineering decisions should focus on technical merit rather than individual preference.

---

# Contribution Review

Limoxel follows a maintainer approval model.

Project decisions, including the acceptance or rejection of contributions, are made according to the project's engineering principles, architectural standards, repository organization, documentation quality, and long-term vision.

Disagreement with a technical decision is not, by itself, considered inappropriate behavior.

Contributors are expected to respect the outcome of the review process, even when a contribution is not accepted.

---

# Enforcement

Project maintainers are responsible for interpreting and enforcing this Code of Conduct.

Depending on the severity of a violation, maintainers may:

- Provide guidance or clarification.
- Request corrective action.
- Remove inappropriate content.
- Temporarily restrict participation.
- Permanently prohibit participation in the project.

Enforcement decisions are made with the goal of preserving a professional, respectful, and productive engineering community.

---

# Scope

This Code of Conduct applies to all official Limoxel spaces, including:

- GitHub Issues
- GitHub Discussions
- Pull Requests
- Project documentation
- Community communication channels
- Any other official project interactions

---

# Acknowledgement

By participating in the Limoxel community, contributors agree to follow this Code of Conduct and to help maintain an environment built on professionalism, respect, collaboration, and engineering excellence.
