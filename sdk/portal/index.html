Engineering Intelligence SDK for Go

Programmatic access to repository indexing, knowledge graphs, architectural boundary analysis, semantic navigation, and deterministic change-impact reasoning.

Get Started Explore APIs
go get github.com/unhield/limoxel/sdk

Core Capabilities

Repository & Search

Index multi-language source trees, query symbol locations, and perform multi-domain repository search across files, packages, and symbols.

Knowledge Graph

Traverse structural entity relationships, compute shortest path blast-radii, and export graphs to Mermaid and Graphviz DOT formats.

Architecture & Health

Evaluate multidimensional health scores, inspect architectural layer boundaries, and detect circular package dependencies automatically.

Semantic Navigation

Resolve symbol definitions, find all reference sites across the codebase, and compute incoming and outgoing call hierarchies.

Reasoning & Impact

Predict blast-radius change impacts, assess semantic breaking changes, and receive automated refactoring safety advice.

Event Streaming

Subscribe to real-time repository lifecycle, indexing progress, and analysis completion events via thread-safe Go channels.

Quickstart Snippet

package main import ( "context" "fmt" "log" "github.com/unhield/limoxel/sdk" ) func main() { ctx := context.Background() client, err := sdk.OpenWorkspace(ctx, ".") if err != nil { log.Fatal(err) } defer client.Close() health, _ := client.Analysis().RepositoryHealth(ctx) fmt.Printf("Repository Health: %.1f/100 (Grade: %s)\n", health.OverallScore, health.Grade) }
